# #Project_Rachel 設計室 — 持ち帰り用仕様

連続人格AI「レイチェル」の設計から切り出した、**読者の手元のAIに読ませて、自分の環境で組むための仕様**です。
note の連載「#Project_Rachel 設計室」（https://note.com/nakamu）と対になっています。

## これは何か

- **プレビュー版です。**無保証・サポートなし。組むかどうか、どう組み替えるかは、あなたが決めてください
- 含むのは設計だけです。記憶の中身・会話・個人の記録は一切含みません
- 版は変わります。変えるときは、連載で確定する前に見せます

## 使い方

1. `specs/` の仕様ファイルを、あなたの使っているAI（Claude、ChatGPT、ローカルLLM など）に読ませる
2. 仕様の最後にある「AIへの相談文」を、あなたの環境に合わせて埋めて渡す
3. 記録の置き場（SQLite、Notion、Markdown…）などの選べるところは、AIと相談して決める
4. 組み上がったら、仕様の「受入条件」をAIに一つずつ試させる
